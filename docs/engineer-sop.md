# 3. Engineer Training SOPs
(Standard Operating Procedures)

This is what ensures your system is used correctly in the real world.

## 3.1 Purpose of SOP

To ensure:

- Consistent service quality
- Accurate data capture
- Legal defensibility
- Audit readiness

## 3.2 Pre-Visit Checklist (Engineer Responsibility)

Before starting a visit:

1.  Confirm assigned complaint
2.  Review reported issue
3.  Verify location and contact details
4.  Ensure device is charged
5.  Ensure network connectivity (or offline mode ready)

## 3.3 On-Site Visit Execution SOP
### Step 1: Arrival Confirmation

- Must be performed on location
- Never confirm arrival remotely

### Step 2: Diagnosis

- Always select correct device category
- Avoid “Other” unless necessary
- Complete checklist honestly
- ⚠ Skipping checklist items is a compliance violation

### Step 3: Action Logging

- Describe actions factually
- Avoid blame or speculation
- Use professional language only

  - ❌ “It happens frequently”
  - ✅ “Intermittent behavior observed during testing”

### Step 4: Parts Replacement

- Never replace assets without logging
- Always verify serial numbers
- One asset = one record

### Step 5: Downtime Handling

- Do not proceed without approval
- Clearly explain downtime to client
- Obtain acknowledgment before action

### Step 6: Outcome Selection

- **Resolved** → requires user confirmation
- **Follow-up** → no signature
- **Observation** → no closure

### Step 7: User Confirmation

- Explain work clearly
- Ask user to review
- Capture signature after explanation
- Never pre-fill ratings

## 3.4 Prohibited Actions (Strict)

- ❌ Backdating visits
- ❌ Editing completed visits
- ❌ Signing on behalf of user
- ❌ Using casual or slang language
- ❌ Completing workflow without actual visit

## 3.5 Post-Visit Responsibility

- Submit visit immediately
- Verify report preview
- Escalate unresolved issues
- Do not promise outcomes outside system

## 3.6 Engineer Accountability

Failure to follow SOP may result in:

- Visit rejection
- SLA penalties
- Audit flags
- Disciplinary action
