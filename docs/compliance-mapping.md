# 2. PDF TYPOGRAPHY & SPACING RULES
(So the report looks enterprise-grade, not system-generated)

This is non-negotiable for professional perception.

- **Page size:** A4
- **Margins:**
  - Top: 24mm
  - Bottom: 20mm
  - Left/Right: 18mm
- **Header height:** 18mm
- **Footer height:** 15mm

## 2.4 Visual Rules
- Section separators: light gray horizontal line
- No boxed clutter
- Use semantic grouping, not tables everywhere
- Signature box minimum height: 70mm

# 3. LEGAL-REVIEWED SERVICE REPORT FORMAT
(Two versions: Client Copy & Engineer/Internal Copy)

## 3.1 CLIENT COPY (Externally Shareable)
- **Includes:**
  - Service summary
  - Issue & resolution
  - Timeline
  - Downtime acknowledgment
  - Signature
  - Feedback
- **Excludes:**
  - Internal notes
  - Engineer observations not shared
  - Root cause speculation

## 3.2 ENGINEER / INTERNAL COPY
- **Includes:**
  - Everything in Client Copy
  - Diagnostic checklist
  - Technical notes
  - Asset failure trends
  - Internal remarks
  - SLA breach reasons (if any)
